# 2. Justificativa: 

Basketic é um projeto pessoal que trabalha em cima do meu hobby predileto, ele visa mensurar as partidas, vitórias e cestas a fim de fazer a contagem dessas métricas para controle do jogo e evolução. 

 

# 3. Objetivo: 

Construir uma plataforma capaz de lucidar o usuário de suas Cestas, Tempo de Jogo, Partidas jogadas e Partidas ganhas. 

 

Representação de uma cesta: https://www.365scores.com/pt-br/news/magazine/wp-content/uploads/2023/02/GettyImages-686677125-scaled.jpg 

# 4. Escopo 

O projeto se deve por um site que o usuário coloca as informações diariamente sobre suas cestas, tempo de jogo, partidas (ganhas e totais). Através dessas informações o algoritmo projeta uma Dashboard que descreve os desempenhos desses valores informados, em relação aos dias que o usuário informou. Tudo isso em forma de gráficos e indicadores, assim, o usuário ganha acesso à essa Dashboard e pode consultar seus dados assimilando sua evolução.

# 6. Metodologia 

A metodologia escolhida para o regimento desse projeto foi o, Kanban. Uma metodologia simples mais eficaz, criada por Taiichi Ohno. Ela consiste na divisão dos requisitos em três seções, Fazer; Fazendo e Feito. 

 

# 7. Riscos do projeto 

Basketic é um projeto que poder ter vários riscos que comprometem sua funcionalidade básica. 

 

# 8. ODS(ONU) 

O Basketic é um projeto que simpatiza perfeitamente com a ODS de número 3, que por sua vez visa melhor a qualidade de vida da humanidade através de variadas práticas, incluindo o esporte e exercício físico. Esse propósito se comunica tão bem com o projeto, que foi decidido que o Basketic irá representar essa ODS, e em conjunto, nós da Basketic consideremos nós como apoiadores dessa causa. 

 

Logo da ODS: https://gtagenda2030.org.br/wp-content/uploads/2019/10/ods3.jpg?w=640
